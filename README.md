
# toolkit

Консольный набор утилит: калькулятор и конвертер величин.

## Установка

pip install -e .

## Команды

Калькулятор:
python -m toolkit calc "2+2*2"

Конвертер:
python -m toolkit convert 100 --from cm --to m

Справка:
python -m toolkit --help

## Что внутри

Калькулятор (calc):
- Поддержка +, -, *, /, //, %.
- Соблюдение приоритета операций.
- Унарный минус (например, -5, 3 + -5).
- Обработка ошибок: недопустимый символ, пропущенный операнд, деление на ноль.
- История успешных вычислений пишется в history.json.

Конвертер (convert):
- Группы: длина (mm, cm, m, km), масса (g, kg), температура (c, f, k).
- Регистр единиц не важен (например, CM == cm).
- Запрещена конвертация между разными группами (например, m в kg).
- Запрещена температура ниже абсолютного нуля.

## Тесты

Запуск:
pytest
